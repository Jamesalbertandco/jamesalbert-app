# James Albert English Institute – school app

The school app for jamesalbert® / James Albert Language Institute®, served at **https://app.jamesalbert.it**.

- `index.html` – the app (all screens, English/Italian). Edit the **SETTINGS** block near the bottom to update news, courses, hubs and the library.
- `images/`, `icons/` – photos, crest, wordmark and app icons.
- `manifest.json`, `sw.js` – lets the app install on phones and work offline.
- `.well-known/assetlinks.json` – links this site to the Google Play app.
- `CNAME` – the custom address for GitHub Pages.
